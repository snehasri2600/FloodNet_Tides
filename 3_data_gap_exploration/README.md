# data_gap_exploration pipeline

Investigates the 2025 FloodNet public-data gap: sensors with real exposure but zero
logged flood events, and whether the manually-logged missing events are corroborated
by rain, tide/surge, or nearby 311 calls.

## Run order

1. **`1_gap_tiers/FloodNet_2025_Data_Gap.ipynb`** — sizes the gap across the full
   415-sensor network (no dependency on the other notebooks; always fetches live
   from the Socrata API).
   - reads: `../final_deployed_sensors.csv`
   - writes: `floodnet_full_network_gap_tiers.csv`
2. **`2_weather/Weather_Data_Scrape.ipynb`** — pulls NCEI precipitation and checks
   each manually-logged QC event for a nearby rain driver.
   - reads: `FloodNet_Data_Manual_QC.csv`, `../final_deployed_sensors.csv`
   - writes: `nyc_precipitation_by_date.csv`, `qc_rain_driver_check.csv`
3. **`3_tidal/Tidal_Corroboration.ipynb`** — checks each QC event against
   astronomical tide height and storm surge.
   - reads: `FloodNet_Data_Manual_QC.csv`, `2_weather/qc_rain_driver_check.csv`,
     `../tidal_analysis/tidal_unified.geojson`, `../final_deployed_sensors.geojson`
   - writes: `noaa_observed_water_levels.csv` (cache, gitignored),
     `tidal_corroboration_events.csv`
4. **`4_311/311_Call_Verification.ipynb`** — checks each QC event against nearby
   same-day 311 flooding complaints, then combines rain/tide/311 into one
   corroboration score.
   - reads: `FloodNet_Data_Manual_QC.csv`, `3_tidal/tidal_corroboration_events.csv`,
     `../final_deployed_sensors.csv`
   - writes: `flooding_311_2025.csv` (cache, gitignored)

`FloodNet_Data_Manual_QC.csv` (the hand-logged missing-event dates) is a shared
manual input read by notebooks 2–4, not regenerated by any of them.

## Reruns

Notebooks 2–4 cache their API pulls (`FORCE_REFRESH = False`), so rerunning them is
fast and hits no external API unless a cache file is missing. Notebook 1 has no
cache and always fetches live from NYC Open Data.
